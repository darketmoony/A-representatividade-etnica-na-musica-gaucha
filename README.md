# A representatividade étnica na música gaúcha

Site da pesquisa *A representatividade étnica na música gaúcha: análise das representações e invisibilização étnicas nos festivais nativistas*, de Emily Paiz de Souza Scaim (orientação: Bolívar Kieling Júnior), do curso Técnico em Multimídia Integrado ao Ensino Médio do IFRS – Campus Vacaria (2026).

Site estático (HTML, CSS e JavaScript). Para ver, abra `index.html` no navegador.

## Onde editar o conteúdo

| O quê | Arquivo |
|---|---|
| Análises das 27 músicas | `assets/js/dados/analises.js` |
| Links e letras das músicas | `assets/js/dados/letras.js` |
| Textos do mapa (povos) | `assets/js/dados/povos.js` |
| Classificação usada nos gráficos | `assets/js/dados/resultados.js` |
| Conceitos, festivais, biografias, sobre | HTML de cada página |
